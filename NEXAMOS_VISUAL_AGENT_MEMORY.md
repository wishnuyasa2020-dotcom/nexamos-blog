# NEXAMOS VISUAL AGENT MEMORY

**Status:** Persistent Agent Rules  
**Canonical Reference:** `NexaMOS_Visual_Language_Bible_v1.0.md`

## 1. Fungsi
Ini adalah memori kerja ringkas agent untuk produksi visual editorial NexaMOS. Jika butuh detail atau terjadi konflik interpretasi, rujuk Bible sebagai Source of Truth.

## 2. North Star — LOCKED
> **Making the invisible marketing system visible.**

Visual harus menjelaskan mekanisme pemasaran, bukan sekadar topiknya.

Model mental:
`MARKET → SIGNAL → DATA → PATTERN → INTELLIGENCE → DECISION → ACTION → RESPONSE → LEARNING`

NexaMOS = **Marketing Operating System**, bukan sekadar CRM, dashboard, database kontak, atau WhatsApp automation.

## 3. Visual DNA — LOCKED
Default: **futuristic editorial technology illustration + abstract system/data visualization + subtle dimensional 3D depth.**

Karakter: intelligent, systematic, technological, premium, precise, contemporary, editorial, sophisticated tetapi tidak ramai.

Default canvas: **deep black / near-black**.

## 4. Core Palette — LOCKED
- Green `#00D690` = action, growth, progression, conversion
- Teal `#04B394` = relationship, customer connection, active entity
- Cyan/Teal `#03A0A7` = data, intelligence, computation, technology
- Black `#000000` = system/environment
- White `#FFFFFF` = clarity/information

Signature gradient:
`#00D690 → #04B394 → #03A0A7`

Gradient bukan dekorasi. Gunakan secara semantik untuk signal, data flow, intelligence, progression, decision, action, atau conversion.

## 5. Visual Grammar — LOCKED
- Market = distributed network/field
- Audience/Unknown = anonymous/low-definition nodes
- Known Profile = identified/illuminated node
- Lead = active identified node + verified signal
- Prospect = qualified node yang lolos filter
- Opportunity = node melewati commitment/decision gate
- Customer = stable/high-confidence activated node
- Signal = pulse/particle/light event
- Data = directional stream
- Identity = node becoming defined/connected
- Relationship = connection/link
- Journey = directional path
- Qualification = filter
- Intent = directional tendency menuju path
- Commitment = crossing a meaningful gate
- Conversion = visible state transformation
- Strategy = selected path among alternatives
- Decision = branching point/gate
- CRM = relationship + state network
- Intelligence = meaningful pattern emerging from signals
- AI = computational layer/mesh/processing field
- Automation = repeated structured flow
- Growth = expanding/replicating system
- Feedback = circular returning path
- Engine = modular processing structure
- Ecosystem = interconnected systems/entities

Utamakan transformasi state pada entitas yang sama daripada ikon berbeda untuk setiap lifecycle state.

## 6. Closed-Loop Geometry — LOCKED
Gunakan concentric rings, orbit, curved streams, circular paths, radial networks, feedback loops, atau spiral movement secara subtil untuk feedback, learning, iteration, progression, optimization, dan closed-loop behavior.

Jangan tempel logo di setiap ilustrasi. Brand harus dikenali dari visual logic.

## 7. One Image = One Idea — LOCKED
Setiap hero image harus punya **SATU dominant idea**.

Prioritas:
1. satu dominant hero mechanism;
2. supporting nodes/signals seperlunya;
3. strong hierarchy;
4. substantial negative space;
5. strong silhouette;
6. thumbnail readability.

Objek yang tidak membantu menjelaskan dominant idea harus dihapus.

## 8. Representation Rules
**AI:** computational capability/layer, bukan robot.  
**CRM:** relationship and state network around identifiable customers.  
**Marketing Intelligence:** `SIGNALS → PATTERN → ANALYSIS → INTELLIGENCE`.  
**Strategy:** choice; gunakan path, branching, constraint, gate, trade-off, territory, concentration.  
**Lifecycle:** `UNKNOWN/AUDIENCE → KNOWN PROFILE → LEAD → PROSPECT → OPPORTUNITY → CUSTOMER → LOYAL/ADVOCATE`; tampilkan sebagai state transition.

## 9. Anti-Patterns — LOCKED
Hindari secara default:
- humanoid robot / robot head
- glowing AI brain
- generic circuit-board brain
- fake dashboard / fake software UI
- random financial charts
- generic office workers / meetings / handshakes
- smartphone cliché
- excessive floating icons
- cyberpunk city
- rainbow/excessive neon
- heavy lens flare
- visual clutter
- decorative gradient tanpa fungsi
- embedded headline
- giant logo sebagai pengganti ide
- imitasi signature visual brand lain

Target = **editorial technology**, bukan sci-fi entertainment atau generic SaaS advertising.

## 10. Daily Workflow — MANDATORY
Saat user meminta **“Bikin hero image artikel ini sesuai NexaMOS Visual System”** atau instruksi semakna:

### STEP 1 — READ
Baca artikel/draft/brief secara utuh.

### STEP 2 — REDUCE
Temukan satu dominant visual proposition. Tentukan mekanisme paling penting yang harus terlihat.

### STEP 3 — MAP
Identifikasi:
`article_topic`, `dominant_idea`, `system_mechanism`, `hero_object`, `NexaMOS primitives`, `state/transformation`, `movement`, `semantic color roles`, `supporting elements`, `must_avoid`.

### STEP 4 — SELECT FAMILY
- **A System Objects:** CRM, architecture, automation, integrations, data infrastructure.
- **B Entity & Lifecycle:** lead, prospect, opportunity, customer, journey, qualification.
- **C Intelligence:** analytics, market intelligence, AI, signals, insight.
- **D Strategic Choice:** strategy, positioning, competition, category, value innovation.

### STEP 5 — BUILD VISUAL BRIEF
```yaml
article_topic:
dominant_idea:
visual_story:
hero_object:
nexamos_primitives:
movement:
semantic_color_role:
composition:
background: "deep black / near-black"
depth_and_material:
negative_space:
must_avoid:
output_ratio: "16:9"
preferred_master_size: "1536x864 or larger"
```

### STEP 6 — BUILD FINAL PROMPT
Ubah brief menjadi natural-language image-generation prompt dengan NexaMOS DNA, semantic palette, one-image-one-idea, negative space, system primitives, dan tanpa embedded headline secara default.

### STEP 7 — GENERATE
Generate dengan image-generation capability yang tersedia. Jangan meminta user menyusun prompt teknis bila artikel sudah cukup.

### STEP 8 — QA
Jalankan Quality Gate. Jika gagal, refine/regenerate.

### STEP 9 — IMPLEMENT
Untuk editorial web:
- default 16:9;
- master 1536×864 atau lebih besar;
- thumbnail-readable;
- safe central composition;
- hindari critical content dekat crop-sensitive edges;
- WebP/AVIF jika didukung;
- meaningful alt text tanpa keyword stuffing;
- support large image preview;
- gunakan image optimization Next.js bila project memakai Next.js.

## 11. Visual Quality Gate — MANDATORY
Sebelum approve:
- [ ] satu dominant idea jelas
- [ ] mekanisme artikel terlihat
- [ ] terasa NexaMOS tanpa logo
- [ ] palette digunakan secara semantik
- [ ] primitives sesuai konsep
- [ ] movement/state transformation jelas
- [ ] dark environment konsisten
- [ ] glow terkendali
- [ ] negative space cukup
- [ ] hero mechanism kuat
- [ ] thumbnail-readable
- [ ] bukan generic AI/SaaS stock image
- [ ] tidak clutter
- [ ] tidak melanggar anti-pattern
- [ ] konsisten dengan visual NexaMOS sebelumnya

Jika spektakuler tetapi keluar dari visual universe NexaMOS: **REJECT**.

**Consistency beats novelty.**

## 12. Editorial Integrity
Jangan membuat statistik palsu, integrasi palsu, fake screenshot sebagai UI asli, hasil customer palsu, endorsement palsu, atau klaim visual yang lebih kuat daripada isi artikel.

## 13. Operational Formula
> **Dark System + Nexa Gradient + Semantic Nodes + Information Flow + Circular Intelligence + One Dominant Idea**

`ENTITY + SIGNAL + STATE + FLOW + DECISION + FEEDBACK`

Gunakan hanya elemen yang diperlukan.

Bukan:
