# NexaMOS Blog

## NexaMOS Blog Architecture

Mental model:

KNOWLEDGE
↓
AGENT
↓
ENGINES
↓
CONTENT
↓
EDITORIAL OPS
↓
APP
↓
DATA
↓
KNOWLEDGE

### Separation of concerns

- `/knowledge` = apa yang NexaMOS tahu dan percaya
- `/agent` = bagaimana AI harus bekerja
- `/engines` = bagaimana rules diimplementasikan
- `/content` = editorial assets
- `/editorial-ops` = workflow state
- `/app` = website/product layer
- `/data` = evidence dan measurement
