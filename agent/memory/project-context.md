# NexaMOS Blog Project Context

NexaMOS Blog adalah owned knowledge publishing system.

Tiga knowledge territory utama:

1. Intelligence
2. Strategy
3. Tactical

Tujuan utama project:

- membangun authority;
- menghasilkan original knowledge;
- Search visibility;
- Google Discover visibility;
- generative AI visibility;
- audience development;
- demand generation;
- closed-loop marketing learning.

Knowledge project harus dipisahkan dari application code.

Folder `knowledge/` adalah source of truth konseptual.

Folder `agent/` berisi instruksi operasional AI agent.

Folder `engines/` berisi implementation logic.

Folder `content/` berisi editorial assets.
