# NexaMOS Editorial Operations

Lifecycle:

BACKLOG
↓
RESEARCH
↓
APPROVED
↓
PRODUCTION
↓
REVIEW
↓
PUBLISHED

Folder ini mengelola state produksi artikel.

Jangan gunakan folder ini sebagai canonical storage artikel final jika artikel final sudah berada di `/content`.

## Folder Boundary & Convention

### `/editorial-ops/production`
Untuk:
- working brief;
- outline sementara;
- working notes;
- editorial instruction;
- production artifacts.

### `/editorial-ops/review`
Untuk:
- review result;
- revision note;
- QA findings;
- validation result.
