# NexaMOS Blog Engines

Folder ini berisi decision dan validation engines untuk content operating system NexaMOS.

## Engines

### Ideation Engine
Mengelola discovery, classification, dan scoring ide artikel.

### Editorial Engine
Mengelola outline, generation, editorial scoring, dan fact validation.

### SEO Validator
Memvalidasi technical/on-page/content search readiness.

### Discover Validator
Memvalidasi originality, headline, depth, dan Discover readiness.

### AI Visibility Engine
Memvalidasi entity clarity, citation readiness, answerability, dan generative AI retrieval readiness.

## Rule

Engines tidak boleh menentukan doctrine.

Doctrine berasal dari:

`/knowledge/`

Agent behavior berasal dari:

`/agent/`
