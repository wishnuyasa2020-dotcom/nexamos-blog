# NexaMOS Knowledge Base

Folder ini adalah source of truth konseptual NexaMOS Blog.

Jangan meletakkan application logic di folder ini.

Struktur:

- `doctrine/` = prinsip dan doktrin utama
- `frameworks/` = model dan framework NexaMOS
- `editorial/` = editorial dan visual standards
- `references/` = sumber teori dan external references
- `research/` = hasil riset internal maupun eksternal

## Folder Boundary & Convention

### `/knowledge/research`
Untuk:
> Original / proprietary research NexaMOS.
Contoh:
- survey internal;
- proprietary benchmark;
- internal observation;
- original datasets;
- internal experiments.

### `/knowledge/references/research`
Untuk:
> External research yang menjadi referensi.
Contoh:
- Pew Research;
- academic paper;
- Ahrefs research;
- industry report;
- official report.

Jika implementasi kode bertentangan dengan knowledge base, tandai konflik untuk human review.
